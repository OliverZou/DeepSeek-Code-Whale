# Whale Pod 需求规格

## 1. 概述

Whale Pod 是一个桌面应用（Wails v2），内嵌 team_engine，独立管理任务编排。无边框窗口，左侧 Sidebar + 右侧面板的两栏布局。

## 2. 界面框架

### 2.1 整体布局

```
┌─────────────────────────────────────────────┐
│  🐳 Whale Pod                    ─  □  ✕   │  ← frameless 自绘标题栏
├────────────┬────────────────────────────────┤
│  Sidebar   │        Right Panel             │
│  (可拖拽)  │                                │
│            │                                │
│  + 新建    │   新建任务 / 专家面板           │
│  🧠 专家   │   / 任务观察 / 对话            │
│            │                                │
│  📌 置顶   │                                │
│  📁 工作空间│                               │
│  👥 AI团队 │                                │
│  ☰ 任务   │                                │
│            │                                │
└────────────┴────────────────────────────────┘
```

### 2.2 Sidebar 结构（从上到下）

| 区块 | 说明 | 折叠 |
|------|------|------|
| 新建任务 / 专家 | 两个按钮，切换右侧面板 | — |
| 置顶任务 | 用户置顶的常用任务 | ✓ |
| 工作空间 | 已打开目录列表 + 任务计数，点击打开目录 | ✓ |
| AI 团队 | 从专家面板召唤的专家团和专家，快捷入口 | ✓ |
| 任务 | 按工作空间分组的完整任务列表 | ✓ |

### 2.3 Right Panel 路由

| activeFunction | 面板内容 |
|----------------|---------|
| `'create'`（默认） | 新建任务面板 |
| `'expert'` | 专家面板 |
| 其他 / 选中任务 | 任务观察 / 对话视图 |

## 3. 新建任务面板

### 3.1 布局

- 顶部：Whale 图标 + "Whale Pod Team Agent" 标题
- "运行于" + 工作空间选择器（目录名 + 下箭头 ▼）
- 输入框（多行文本，placeholder "描述计划"）
- 输入框右下角：发送按钮
- 输入框左下角：团队选择器（极小模式，文字 + 下箭头）
- 底部：快捷提示按钮（分析股票、编写策略…）

### 3.2 工作空间选择器

选项来源：
1. 当前及历史打开过的目录
2. "选择文件夹…" — 调用系统原生对话框
3. "不用工作空间"

显示只展示目录名，系统内部持有完整路径。

### 3.3 团队选择器

选项：
- "无团队"（默认）
- 已召唤的 AI 团队列表
- "召唤其他专家…" — 切换到专家面板

## 4. 专家面板

展示可用的专家角色，用户选择后召唤到 AI 团队中。（待细化）

## 5. Sidebar 章节

### 5.1 置顶任务

用户可将任务置顶，在此快速访问。（待细化）

### 5.2 工作空间

列出所有打开过的目录，每项显示任务数。右侧有 📁+ 按钮打开目录。

### 5.3 AI 团队

数据来源：`whale-pod.exe 所在目录\teams\`（目录名为团队名，内部为 YAML 配置文件）。

已召唤的专家团和专家列表。有"添加团队"和"添加 Agent"按钮。

### 5.4 任务

按工作空间目录分组展示所有任务。每项显示：状态图标、目标摘要、完成数/总数、进度条。

## 6. 设计规范

### 6.1 图标

- 统一使用单色线条 SVG
- 下拉/折叠箭头：统一三角 SVG（8×5），闭合向右旋转、展开向下
- 文件夹：平面线条 SVG
- 应用图标：`whale.png`（512×512）→ `appicon.png` → 构建时生成 ICO

### 6.2 交互

- 按钮默认透明无边框，hover 时浅灰背景+淡边框，选中时绿色背景+绿色边框
- 折叠章节：点击标题行展开/收起
- Combobox：点击展开下拉菜单，外部点击关闭

### 6.3 色彩

| 用途 | 色值 |
|------|------|
| 背景 | `#141414` |
| 面板背景 | `#1e1e1e` |
| 边框 | `#333` |
| 主文字 | `#e0e0e0` |
| 次要文字 | `#888` |
| 强调色（绿） | `#4CAF50` |
| 强调色（蓝） | `#2196F3` |

## 7. 构建

```batch
build_whale_pod.bat:
  Step 0: whale.png → appicon.png（gen_icon.go）
  Step 1: npm build 前端
  Step 2: wails build  Go 二进制
```

产物：`bin/whale-pod.exe`
